      VeloDB 本地 MCP 服务
      
    

    

      

        VeloDB 将当前数据库连接与 Schema 能力通过标准 MCP (Model Context Protocol) 暴露给你的外部 Agent（Claude Code / Cursor / Antigravity）。
      

      

        

          
Agent 只读安全锁

          
仅暴露 list_schemas / describe_table / run_read_query / explain_query

        

        已启用
      

      

        
客户端配置 (mcp_config.json)

        
{
  "mcpServers": {
    "velodb": {
      "command": "/Applications/VeloDB.app/Contents/MacOS/velodb-mcp",
      "args": ["--connection", "velodb_prod_us_east", "--read-only"]
    }
  }
}
